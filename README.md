# Dotfiles
My most important config files.

## Distro
I've used a lot of different distros and came to the conclusion that it is
unimportant.

## Nvim
I used to use Neovim, but I switched to **helix**. If you want
to take a look at my old unmaintained config, [here it is](https://github.com/RyanQueirozS/nvim-conf).

## Window manager
I used to use i3, that's why there are a lot of i3 and X related program configs
in here - in case I decide to switch back to it later on. Now I'm using Niri, no
real reason behind it, just trying something new.

## Discaimer
Some of the configs in there were not created by me. I try to give credit to the
creators, but if I've missed one, please tell me. If you think that you might
like these configs, try it out and tell me where you think I could improve them.

## setup.sh
`setup.sh` is to create the directories and symbolic links for the config, you
might not need it.
